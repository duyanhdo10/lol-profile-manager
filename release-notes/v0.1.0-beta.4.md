## English

- Add automatic update checks through GitHub Releases.
- Download new versions in the background and install only after explicit confirmation.
- Add download progress, manual update checks, and a restart prompt that protects pending profile changes.
- Validate the installer, update metadata, and blockmap on GitHub before publishing the Release as Latest.

> This beta is not code-signed yet. Windows may show a SmartScreen warning during installation.

## Tiếng Việt

- Thêm kiểm tra cập nhật tự động qua GitHub Releases.
- Tải phiên bản mới trong nền và chỉ cài đặt sau khi người dùng xác nhận rõ ràng.
- Thêm tiến trình tải, nút kiểm tra thủ công và cảnh báo khi khởi động lại có thể làm mất thay đổi hồ sơ chưa áp dụng.
- Kiểm tra bộ cài, metadata cập nhật và blockmap trên GitHub trước khi phát hành Release thành bản Latest.

> Bản beta này chưa được ký mã. Windows có thể hiển thị cảnh báo SmartScreen khi cài đặt.
