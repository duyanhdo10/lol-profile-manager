## English

- Replace the application artwork with the new LoL Profile Manager icon.
- Use the multi-size ICO for the Windows executable, app window, installer, uninstaller, and favicon.
- Keep the matching transparent PNG for the navigation, profile fallback, and documentation.

> This beta is not code-signed yet. Windows may show a SmartScreen warning during installation.

## Tiếng Việt

- Thay hình ảnh nhận diện ứng dụng bằng icon LoL Profile Manager mới.
- Dùng file ICO đa kích thước cho executable Windows, cửa sổ ứng dụng, bộ cài, trình gỡ cài đặt và favicon.
- Giữ file PNG nền trong suốt tương ứng cho thanh điều hướng, ảnh hồ sơ dự phòng và tài liệu.

> Bản beta này chưa được ký mã. Windows có thể hiển thị cảnh báo SmartScreen khi cài đặt.
