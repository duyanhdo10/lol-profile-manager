## English

- Restore Showcase Apply compatibility with the current League Client response format for titles, challenge tokens, and banners.
- Send the numeric title item ID expected by LCU while preserving stable content IDs in drafts and previews.
- Read challenge and banner ownership from the correct LCU inventories, disable confirmed unowned Showcase items, and keep unknown items selectable offline.
- Avoid marking every selected token or banner incompatible when one combined Showcase request is rejected.
- Center the real Solo/Duo, Flex, and TFT emblem artwork inside its clipped card and overview previews.
- Add regression coverage for current LCU parsing, ownership overlays, title Apply payloads, and emblem positioning.

> This beta is not code-signed yet. Windows may show a SmartScreen warning during installation.
